# Movie and Employee Review Analysis

A data mining and text analysis project exploring two datasets: IMDb's top movies and employee reviews of Tata Motors, using RapidMiner and Excel.

## Overview

This project applies data mining and spreadsheet analysis techniques to two unrelated datasets. The first analysis looks at trends in IMDb's top-rated movies, and the second mines employee reviews of Tata Motors to surface common concerns.

## Key Findings

- **Employee reviews:** Association rule mining on the Tata Motors reviews identified recurring concerns around work-life balance and career growth.
- **Movies:** Excel functions and PivotTables showed that 2018 had the most releases in the dataset, but a lower average gross than other years.

## Approach

- Cleaned both datasets before analysis
- Built association rules in RapidMiner to find patterns in the employee review data
- Used Excel functions and PivotTables to explore the movie dataset and answer a range of questions about release trends and earnings by year

## Datasets

Both datasets are public and available on Kaggle:
- [IMDb Top Movies](https://www.kaggle.com/datasets/ashutoshdevpura/imdb-top-10000-movies-updated-august-2023/)
- [Tata Motors Employee Reviews](https://www.kaggle.com/datasets/manishkr1754/tata-motors-employee-reviews-dataset)
